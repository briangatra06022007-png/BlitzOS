# Daftar Minimal 10 Paket Utama — BlitzOS
| No | Paket | Alasan Pemilihan |
| :--- | :--- | :--- |
| 1 | `git` | Manajemen versi kode sumber dan kolaborasi GitHub. |
| 2 | `curl` | Pengujian API dan transfer data HTTP/HTTPS via terminal. |
| 3 | `wget` | Pengunduhan berkas dan paket dari terminal secara stabil. |
| 4 | `nano` | Editor teks terminal ringan untuk konfigurasi cepat. |
| 5 | `vim` | Editor teks lanjutan standar lingkungan Linux. |
| 6 | `htop` | Pemantauan penggunaan CPU, RAM, dan proses secara interaktif. |
| 7 | `neofetch` | Menampilkan informasi sistem operasi dan branding BlitzOS. |
| 8 | `zip` | Kompresi berkas dan folder ke format arsip `.zip`. |
| 9 | `unzip` | Ekstraksi arsip `.zip` untuk berkas proyek maupun materi. |
| 10 | `default-jdk` | Lingkungan pengembangan dan kompilasi bahasa Java. |
